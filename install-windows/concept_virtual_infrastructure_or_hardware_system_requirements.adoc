= Informationen zu virtueller Infrastruktur und Hardwareanforderungen für Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Für die Installation von Unified Manager auf virtueller Infrastruktur oder einem physischen System müssen die Mindestanforderungen an Arbeitsspeicher, CPU und Festplattenspeicher erfüllt sein.

Die folgende Tabelle zeigt die empfohlenen Werte für Arbeitsspeicher, CPU und Festplattenspeicher. Diese Werte wurden so qualifiziert, dass Unified Manager akzeptable Performancewerte erreicht.

[cols="2*"]
|===
| Hardwarekonfiguration | Empfohlene Einstellungen 


 a| 
RAM
 a| 
12 GB



 a| 
Prozessoren
 a| 
4 CPUs



 a| 
CPU-Zykluskapazität
 a| 
9572 MHz gesamt (Mindestanforderung 9572 MHz)



 a| 
Freier Speicherplatz
 a| 
150 GB, wobei die Kapazität wie folgt aufgeteilt ist:

* Für das Installationsverzeichnis werden 100 GB Festplattenspeicher benötigt.
* 50 GB Speicherplatz für das MySQL-Datenverzeichnis


|===
Unified Manager kann zwar auch auf Systemen mit wenig Arbeitsspeicher installiert werden, die empfohlenen 12 GB RAM gewährleisten jedoch ausreichend Speicher für optimale Performance, sodass das System bei wachsender Konfiguration zusätzliche Cluster und Storage Objekte aufnehmen kann. Sie sollten keine Speichergrenzen für die VM festlegen, auf der Unified Manager eingesetzt wird, und keine Funktionen (z. B. Ballooning) aktivieren, die die Nutzung des dem System zugewiesenen Arbeitsspeichers durch die Software behindern.

Darüber hinaus gibt es eine Begrenzung für die Anzahl der Knoten, die eine einzelne Instanz von Unified Manager überwachen kann, bevor eine zweite Instanz von Unified Manager installiert wird. Empfehlungen zu Knotenlimits, CPU und Arbeitsspeicher sind unter  https://www.netapp.com/pdf.html?item=/media/13504-tr4621.pdf["der Unified Manager Best Practices-Leitfaden"^] zu finden.

Das Auslagern von Speicherseiten beeinträchtigt die Performance des Systems und der Verwaltungsapplikation. Der Wettbewerb um CPU-Ressourcen, die aufgrund der Gesamtauslastung des Hosts nicht verfügbar sind, kann die Performance beeinträchtigen.



[[requirement-for-dedicated-use]]
== Anforderung für dedizierte Nutzung

Das physische oder virtuelle System, auf dem Sie Unified Manager installieren, sollte ausschließlich für Unified Manager vorgesehen sein und nicht mit anderen Applikationen gemeinsam genutzt werden. Andere Applikationen könnten Systemressourcen beanspruchen und die Performance von Unified Manager erheblich beeinträchtigen.



[[space-requirements-for-backups]]
== Speicherplatzbedarf für Backups

Wenn Sie die Backup- und Restore-Funktion von Unified Manager verwenden möchten, weisen Sie zusätzliche Kapazität zu, sodass das Verzeichnis oder die Festplatte "`data`" über 150 GB Speicherplatz verfügt. Ein Backup kann auf ein lokales Ziel oder auf ein Remote-Ziel geschrieben werden. Die Best Practice besteht darin, einen Remote-Speicherort außerhalb des Unified Manager Host-Systems zu bestimmen, der über mindestens 150 GB Speicherplatz verfügt.



[[requirements-for-host-connectivity]]
== Anforderungen an die Host-Konnektivität

Das physische oder virtuelle System, auf dem Sie Unified Manager installieren, muss so konfiguriert sein, dass Sie den Hostnamen vom Host selbst aus erfolgreich `ping` können. Bei einer IPv6-Konfiguration sollten Sie prüfen, ob `ping6` zum Hostnamen erfolgreich ist, damit die Installation von Unified Manager erfolgreich verläuft.

Sie können den Hostnamen (oder die Host-IP-Adresse) verwenden, um auf die Web-UI des Produkts zuzugreifen. Wenn Sie während des Deployment eine statische IP-Adresse für Ihr Netzwerk konfiguriert haben, haben Sie dem Netzwerkhost einen Namen zugewiesen. Wenn Sie das Netzwerk mit DHCP konfiguriert haben, sollten Sie den Hostnamen über DNS beziehen.

Wenn Sie Benutzern den Zugriff auf Unified Manager über den Kurznamen anstelle des vollqualifizierten Domain-Namens (FQDN) oder der IP-Adresse ermöglichen möchten, muss Ihre Netzwerkkonfiguration diesen Kurznamen in einen gültigen FQDN auflösen.
