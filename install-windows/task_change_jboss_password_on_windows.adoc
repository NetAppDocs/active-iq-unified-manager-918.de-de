= Änderung des JBoss Passworts unter Windows in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können das während der Installation festgelegte instanzspezifische JBoss Passwort zurücksetzen. Das Zurücksetzen des Passworts ist optional, falls Ihr Standort diese Sicherheitsfunktion benötigt, um die Installationseinstellung von Unified Manager zu überschreiben. Durch diesen Vorgang wird auch das Passwort geändert, das JBoss für den Zugriff auf MySQL verwendet.

.Bevor Sie beginnen
* Sie benötigen Windows-Administratorrechte für das System, auf dem Unified Manager installiert ist.
* Sie sollten das Passwort für den MySQL Root-Benutzer haben.
* Sie sollten auf das von NetApp bereitgestellte `password.bat` Skript im Verzeichnis zugreifen können.
+
`C:\Program Files\NetApp\essentials\bin`.



.Schritte
. Sie melden sich auf dem Unified Manager-Hostrechner als admin-Benutzer an.
. Beenden der folgenden Unified Manager Services in der Windows Services Managementplattform:
+
** NetApp Active IQ Acquisition Service (Ocie-au)
** NetApp Active IQ Management Server Service (Oncommandsvc)


. Der Passwortänderungsprozess beginnt mit dem Starten des `password.bat` Skripts:
+
`C:\Program Files\NetApp\essentials\bin> password.bat resetJBossPassword`

. Wenn Sie dazu aufgefordert werden, geben Sie das Passwort des MySQL Root-Benutzers ein.
. Bei der entsprechenden Aufforderung ist das neue JBoss-Benutzerpasswort einzugeben und anschließend zur Bestätigung erneut einzugeben.
+
Das Passwort sollte zwischen 8 und 16 Zeichen lang sein und mindestens eine Ziffer, einen Groß- und einen Kleinbuchstaben sowie mindestens eines der folgenden Sonderzeichen enthalten:

+
`+!@%^*-_+=[]:<>.?/~+`

. Nach Abschluss des Skripts erfolgt der Start der Unified Manager Services über die Windows Services Managementplattform:
+
** NetApp Active IQ Management Server Service (Oncommandsvc)
** NetApp Active IQ Acquisition Service (Ocie-au)


. Sobald alle Services gestartet sind, können Sie sich bei der Unified Manager Benutzeroberfläche anmelden.
