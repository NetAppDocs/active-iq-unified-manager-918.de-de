= Upgrade von Drittanbieterprodukten in Active IQ Unified Manager unter Windows
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Drittanbieterprodukte wie JRE in Unified Manager aktualisieren, wenn Unified Manager auf Windows-Systemen installiert ist.

Die Unternehmen, die diese Drittanbieterprodukte entwickeln, melden regelmäßig Sicherheitslücken. Sie können die Software nach eigenem Zeitplan auf neuere Versionen aktualisieren.
