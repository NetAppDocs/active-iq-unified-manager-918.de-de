= Informationen zu den Benutzern, die während der Installation von Active IQ Unified Manager erstellt wurden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Bei der Installation von Unified Manager auf Red Hat Enterprise Linux werden durch Unified Manager und Drittanbieter-Dienstprogramme die folgenden Benutzer erstellt: umadmin, jboss und mysql.

* *umadmin*
+
Wird für die erste Anmeldung bei Unified Manager verwendet. Diesem Benutzer ist die Benutzerrolle "`Application Administrator`" zugewiesen, und er ist als Typ "`Maintenance User`" konfiguriert. Unified Manager erstellt diesen Benutzer.

* *jboss*
+
Dient zum Ausführen von Unified Manager Services im Zusammenhang mit dem JBoss-Dienstprogramm. Dieser Benutzer wird von Unified Manager erstellt.

* *mysql*
+
Dient zum Ausführen von MySQL-Datenbankabfragen von Unified Manager. Das MySQL-Drittanbieter-Dienstprogramm erstellt diesen Benutzer.



Zusätzlich zu diesen Benutzern erstellt Unified Manager auch entsprechende Gruppen: maintenance, jboss und mysql. Die Gruppen maintenance und jboss werden von Unified Manager erstellt, während die Gruppe mysql von einem Drittanbieter-Tool erstellt wird.

[NOTE]
====
Wenn Sie vor der Installation von Unified Manager ein benutzerdefiniertes Home-Verzeichnis erstellt und Ihr eigenes umadmin-Benutzerkennwort definiert haben, werden die Wartungsgruppe und der umadmin-Benutzer vom Installationsprogramm nicht neu erstellt.
