= Das JBoss-Passwort in Active IQ Unified Manager ändern
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können das während der Installation festgelegte instanzspezifische JBoss Passwort zurücksetzen. Das Zurücksetzen des Passworts ist optional, falls Ihr Standort diese Sicherheitsfunktion benötigt, um die Installationseinstellung von Unified Manager zu überschreiben. Durch diesen Vorgang wird auch das Passwort geändert, das JBoss für den Zugriff auf MySQL verwendet.

* Sie benötigen Root-Benutzerzugriff auf das Red Hat Enterprise Linux-System, auf dem Unified Manager installiert ist.
* Sie müssen auf das von NetApp `password.sh` bereitgestellte Skript im Verzeichnis `/opt/netapp/essentials/bin` zugreifen können.


.Schritte
. Am System ist eine Anmeldung als Root-Benutzer erforderlich.
. Die folgenden Befehle dienen dazu, die Unified Manager Services in der angegebenen Reihenfolge zu beenden:
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

+
Die zugehörige MySQL-Software darf nicht angehalten werden.

. Der Prozess zum Ändern des Passworts beginnt mit folgendem Befehl:
+
`/opt/netapp/essentials/bin/password.sh resetJBossPassword`

. Wenn Sie dazu aufgefordert werden, erfolgt die Eingabe des neuen JBoss Passworts und anschließend dessen erneute Eingabe zur Bestätigung.
+
Das Passwort sollte zwischen 8 und 16 Zeichen lang sein und mindestens eine Ziffer, einen Groß- und einen Kleinbuchstaben sowie mindestens eines der folgenden Sonderzeichen enthalten:

+
`+!@%^*-_+=[]:<>.?/~+`

. Nach Abschluss des Skripts erfolgt der Start der Unified Manager Services mit den folgenden Befehlen in der angegebenen Reihenfolge:
+
`systemctl start ocie`

+
`systemctl start ocieau`

. Sobald alle Services gestartet sind, können Sie sich bei der Unified Manager Benutzeroberfläche anmelden.
