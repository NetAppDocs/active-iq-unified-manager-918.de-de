= Informationen zu Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager (formerly OnCommand Unified Manager) ermöglicht die Überwachung und das Managen des Systemstatus und der Performance Ihrer ONTAP Storage Systeme über eine zentrale Benutzeroberfläche. Unified Manager kann auf einem Linux Server, auf einem Windows Server oder als virtuelle Appliance (vApp) auf einem VMware Host eingesetzt werden.

Nachdem Sie die Installation abgeschlossen und die Cluster hinzugefügt haben, die Sie managen möchten, bietet Unified Manager eine grafische Benutzeroberfläche, die den Kapazitäts-, Verfügbarkeits-, Schutz- und Performance-Status der überwachten Storage Systeme anzeigt.
