= Aktualisierung von Drittanbieterprodukten nach der Installation von Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Drittanbieterprodukte wie JRE aktualisieren, wenn Unified Manager bereits auf Linux-Systemen installiert ist.

Die Unternehmen, die diese Drittanbieterprodukte entwickeln, melden regelmäßig Sicherheitslücken. Sie können die Software nach eigenem Zeitplan auf neuere Versionen aktualisieren.
