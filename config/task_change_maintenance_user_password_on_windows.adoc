= Das Kennwort des Wartungsbenutzers unter Windows in Active IQ Unified Manager ändern
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können das Wartungsbenutzerkennwort von Unified Manager bei Bedarf ändern.

.Schritte
. Auf der Anmeldeseite der Unified Manager Web UI können Sie *Forgot Password* auswählen.
+
Es wird eine Seite angezeigt, auf der Sie den Namen des Benutzers eingeben, dessen Passwort Sie zurücksetzen möchten.

. Den Benutzernamen eingeben und auf *Submit* klicken.
+
An die für diesen Benutzernamen definierte E-Mail-Adresse wird eine E-Mail mit einem Link zum Zurücksetzen des Passworts gesendet.

. Das neue Passwort wird über den *Link zum Zurücksetzen des Passworts* in der E-Mail definiert.
. Anschließend erfolgt die Anmeldung bei Unified Manager über die Web-Benutzeroberfläche mit dem neuen Passwort.
