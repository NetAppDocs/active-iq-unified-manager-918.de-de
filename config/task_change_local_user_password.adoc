= Das lokale Benutzerkennwort in Active IQ Unified Manager kann geändert werden.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Ihr Passwort für die Anmeldung als lokaler Benutzer ändern, um potenziellen Sicherheitsrisiken vorzubeugen.

.Bevor Sie beginnen
Sie müssen als lokaler Benutzer angemeldet sein.

Die Passwörter für den Wartungsbenutzer und für Remote-Benutzer können mit diesen Schritten nicht geändert werden. Die Änderung eines Remote-Benutzerpassworts erfolgt über Ihren Passwortadministrator. Informationen zum Ändern des Passworts des Wartungsbenutzers enthält link:task_use_maintenance_console.html["Verwenden der Managementplattform"].

.Schritte
. Sie sind bei Unified Manager angemeldet.
. In der oberen Menüleiste erfolgt die Auswahl zunächst über das Benutzersymbol und anschließend über *Passwort ändern*.
+
Bei Remote-Benutzern ist die Option *Passwort ändern* nicht verfügbar.

. Im Dialogfeld „Passwort ändern“ erfolgt die Eingabe des aktuellen Passworts und des neuen Passworts.
. Auf *Speichern* klicken.


Wenn Unified Manager in einer Hochverfügbarkeitskonfiguration eingerichtet ist, müssen Sie das Passwort auf dem zweiten Knoten des Setups ändern. Beide Instanzen müssen dasselbe Passwort verwenden.
