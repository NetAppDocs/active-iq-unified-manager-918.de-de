= Diagnosefunktionen für Benutzer in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der Diagnosezugriff dient dazu, dass der technische Support Sie bei der Fehlersuche unterstützen kann, und Sie sollten ihn nur auf Anweisung des technischen Supports verwenden.

Der Diagnosebenutzer kann auf Anweisung des technischen Supports Befehle auf Betriebssystemebene zur Fehlerbehebung ausführen.
