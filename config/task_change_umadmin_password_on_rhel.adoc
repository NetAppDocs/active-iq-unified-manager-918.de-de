= Ändern des Active IQ Unified Manager umadmin Passworts auf Linux Systemen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Aus Sicherheitsgründen müssen Sie das Standardpasswort für den Unified Manager-Benutzer „umadmin“ unmittelbar nach Abschluss der Installation ändern. Bei Bedarf können Sie das Passwort später jederzeit erneut ändern.

.Bevor Sie beginnen
* Unified Manager muss auf einem Red Hat Enterprise Linux Linux System installiert sein.
* Sie benötigen die Root-Benutzer-Anmeldedaten für das Linux-System, auf dem Unified Manager installiert ist.


.Schritte
. Die Anmeldung als Root-Benutzer erfolgt auf dem Linux-System, auf dem Unified Manager ausgeführt wird.
. Das Passwort des Benutzers umadmin ändern:
+
`passwd umadmin`

+
Das System fordert Sie auf, ein neues Passwort für den Benutzer umadmin einzugeben.
