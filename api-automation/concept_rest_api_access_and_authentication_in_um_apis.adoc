= Zugriff auf REST APIs und Authentifizierung in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Active IQ Unified Manager REST API ist über jeden REST Client oder jede Programmierplattform zugänglich, die HTTP-Anfragen mit einem grundlegenden HTTP-Authentifizierungsmechanismus ausgeben kann.

+
** `_IP address/hostname_` ist die IP-Adresse oder die vollqualifizierte Domain (FQDN) des API-Servers.
** Port 443
+
443 ist der Standardport für HTTPS. Sie können den HTTPS Port bei Bedarf anpassen.



+
Zum Senden von HTTP-Anfragen aus einem Webbrowser ist die Verwendung von REST API Browser Plugins erforderlich. Der Zugriff auf die REST API ist auch über Skriptplattformen wie cURL und Perl möglich.





[[authentication]]
== Authentifizierung

Unified Manager unterstützt das grundlegende HTTP-Authentifizierungsschema für APIs. Für einen sicheren Informationsfluss (Anfrage und Antwort) sind die REST-APIs nur über HTTPS zugänglich. Der API-Server stellt allen Clients zur Serververifizierung ein selbstsigniertes SSL-Zertifikat bereit. Dieses Zertifikat kann durch ein benutzerdefiniertes Zertifikat (oder ein CA-Zertifikat) ersetzt werden.

Sie müssen den Benutzerzugriff auf den API-Server konfigurieren, um die REST-APIs aufzurufen. Die Benutzer können lokale Benutzer (Benutzerprofile in der lokalen Datenbank) oder LDAP-Benutzer sein (sofern Sie den API-Server für die Authentifizierung über LDAP konfiguriert haben). Der Benutzerzugriff lässt sich verwalten, wenn Sie sich an der Benutzeroberfläche der Unified Manager Administration Console anmelden.
