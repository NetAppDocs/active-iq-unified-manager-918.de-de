= Vorgesehene Benutzer der Active IQ Unified Manager REST APIs
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die hier behandelten Themen richten sich an Entwickler, die Applikationen erstellen, die über REST-APIs mit der Active IQ Unified Manager Software interagieren.

Storage Administratoren und -Architekten können diese Informationen nutzen, um ein grundlegendes Verständnis dafür zu erlangen, wie die Unified Manager REST APIs zum Erstellen von Client Applikationen für das Managen und Überwachen von NetApp Storage Systemen verwendet werden können.

Diese Informationen sind relevant, wenn Sie den Storage-Provider, ONTAP cluster und Management-Administrations-APIs zum Managen Ihres Storage verwenden möchten.

[NOTE]
====
Sie müssen über eine der folgenden Rollen verfügen: Operator, Storage Administrator oder Application Administrator. Sie müssen die IP-Adresse oder die vollqualifizierte Domain des Unified Manager Servers kennen, auf dem Sie die REST APIs ausführen möchten.

====
