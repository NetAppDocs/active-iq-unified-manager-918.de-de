= Ändern einer NFS Dateifreigabe zur Unterstützung von CIFS mithilfe der Active IQ Unified Manager APIs
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können eine NFS-Dateifreigabe ändern, damit sie das CIFS-Protokoll unterstützt. Bei der Erstellung der Dateifreigabe können sowohl Parameter der Zugriffssteuerungsliste (ACL) als auch Exportrichtlinienregeln für dieselbe Dateifreigabe angegeben werden. Wenn Sie CIFS jedoch auf demselben Volume aktivieren möchten, auf dem Sie eine NFS-Dateifreigabe erstellt haben, können Sie die ACL-Parameter dieser Dateifreigabe aktualisieren, damit sie CIFS unterstützt.

.Bevor Sie beginnen
. Eine NFS-Dateifreigabe muss bereits nur mit den Exportrichtliniendetails erstellt worden sein. Informationen dazu enthalten _Managing file shares_ und _Modifying storage workloads_.
. Für diesen Vorgang benötigen Sie den Dateifreigabeschlüssel. Informationen zum Anzeigen von Dateifreigabedetails und zum Abrufen des Dateifreigabeschlüssels mithilfe der Job ID finden Sie unter „Bereitstellen von CIFS- und NFS-Dateifreigaben“.


Dies gilt für eine NFS-Dateifreigabe, die Sie erstellt haben, indem Sie nur Exportrichtlinienregeln und keine ACL-Parameter hinzugefügt haben. Sie ändern die NFS-Dateifreigabe, sodass die ACL-Parameter einbezogen werden.

.Schritte
. Auf der NFS-Dateifreigabe erfolgt ein `PATCH`Vorgang mit den ACL-Details, um CIFS-Zugriff zuzulassen.
+
[cols="3*"]
|===
| Kategorie | HTTP-Verb | Pfad 


 a| 
Storage-Provider
 a| 
PATCH
 a| 
`/storage-provider/file-shares`

|===
+
*Beispiel cURL*

+
Basierend auf den Zugriffsrechten, die Sie der Benutzergruppe zuweisen, wird, wie im folgenden Beispiel dargestellt, eine ACL erstellt und der Dateifreigabe zugewiesen.

+
[listing]
----
{
  "access_control": {
    "acl": [
      {
        "permission": "read",
        "user_or_group": "everyone"
      }
    ],
    "active_directory_mapping": {
      "key": "3b648c1b-d965-03b7-20da-61b791a6263c"
    }
----
+
*Beispielhafte JSON-Ausgabe*

+
Die Operation gibt die Job-ID des Jobs zurück, der das Update ausführt.

. Ob die Parameter korrekt hinzugefügt wurden, lässt sich durch Abfrage der Details der Dateifreigabe für dieselbe Dateifreigabe verifizieren.
+
[cols="3*"]
|===
| Kategorie | HTTP-Verb | Pfad 


 a| 
Storage-Provider
 a| 
GET
 a| 
`/storage-provider/file-shares/\{key}`

|===
+
