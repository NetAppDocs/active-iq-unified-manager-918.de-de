= SVMs auf ONTAP Clustern mithilfe der Active IQ Unified Manager APIs überprüfen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vor der Provisionierung von Dateifreigaben oder LUNs sollte geprüft werden, ob auf den Clustern Storage Virtual Machines (SVMs) erstellt wurden.

[NOTE]
====
Der Workflow setzt voraus, dass ONTAP Cluster zu Unified Manager hinzugefügt wurden und der Clusterschlüssel abgerufen wurde. Die Cluster müssen über die erforderlichen Lizenzen für die Provisionierung von LUNs und Dateifreigaben verfügen.

====
. Es ist zu prüfen, ob im Cluster eine SVM erstellt wurde.
+
[cols="3*"]
|===
| Kategorie | HTTP-Verb | Pfad 


 a| 
Datacenter
 a| 
GET
 a| 
`/datacenter/svm/svms`
`/datacenter/svm/svms/\{key}`

|===
+
*Beispiel cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/svm/svms" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. Wenn der SVM-Schlüssel nicht zurückgegeben wird, muss die SVM erstellt werden. Zum Erstellen der SVMs benötigen Sie den Clusterschlüssel, auf dem Sie die SVM provisionieren. Außerdem müssen Sie den SVM-Namen angeben. Die folgenden Schritte sind auszuführen.
+
[cols="3*"]
|===
| Kategorie | HTTP-Verb | Pfad 


 a| 
Datacenter
 a| 
GET
 a| 
`/datacenter/cluster/clusters`
`/datacenter/cluster/clusters/\{key}`

|===
+
Ermittlung des Cluster-Schlüssels.

+
*Beispiel cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/cluster/clusters" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. Der Cluster-Schlüssel aus der Ausgabe dient anschließend als Eingabe für die Erstellung der SVM.
+
[NOTE]
====
Beim Erstellen der SVM muss sichergestellt werden, dass sie alle für die Provisionierung von LUNs und Dateifreigaben erforderlichen Protokolle unterstützt, z. B. CIFS, NFS, FCP und iSCSI. Die Provisionierungs-Workflows können fehlschlagen, wenn die SVM die erforderlichen Services nicht unterstützt. Es wird empfohlen, die Services für die jeweiligen Workload-Typen ebenfalls auf der SVM zu aktivieren.

====
+
[cols="3*"]
|===
| Kategorie | HTTP-Verb | Pfad 


 a| 
Datacenter
 a| 
POST
 a| 
`/datacenter/svm/svms`

|===
+
*Beispiel cURL*
