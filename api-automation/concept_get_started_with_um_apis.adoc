= Erste Schritte mit Active IQ Unified Manager REST APIs
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager bietet eine Reihe von APIs zum Managen Ihrer Storage Ressourcen auf den unterstützten Storage Systemen über eine RESTful-Webservice-Schnittstelle für beliebige Drittanbieterintegrationen.

In diesen Abschnitten finden Sie Informationen zu den Unified Manager APIs, Beispiel-Workflows zur Behebung spezifischer Probleme sowie Beispielcode. Mithilfe dieser Informationen können Sie RESTful-Clients von NetApp Manageability-Softwarelösungen für das Management von NetApp Systemen erstellen. Die APIs basieren auf dem Architekturstil Representational State Transfer (REST). Alle vier REST-Operationen Create, Read, Update und Delete, auch als CRUD bezeichnet, werden unterstützt.

Zusätzliche Ressourcen und Details zu den Vorteilen der Active IQ Unified Manager REST API finden Sie unter link:https://docs.netapp.com/us-en/netapp-automation/api/aiqum.html["Active IQ Unified Manager"^].
