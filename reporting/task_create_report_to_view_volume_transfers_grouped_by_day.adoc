= Ein Bericht zur Anzeige von nach Tag gruppierten Volume-Übertragungen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können einen Bericht erstellen, um die Volume-Übertragungen nach Tag gruppiert anzuzeigen.

.Bevor Sie beginnen
* Die Rolle Application Administrator oder Storage Administrator ist erforderlich.


Im Folgenden wird beschrieben, wie eine benutzerdefinierte Ansicht für nach Tagen gruppierte Volume-Übertragungen erstellt und anschließend ein Bericht für diese Ansicht generiert wird.

.Schritte
. Auswahl im linken Navigationsbereich: *Storage* > *Volumes*.
. Im Menü „Ansicht“ ist *Beziehung* > *Übertragungsrate des letzten Monats* auszuwählen.
. Ein Klick auf den oberen Rand der Spalte „`Day`“ sortiert die Volume-Übertragungen nach Tag.
. Die Ansicht kann unter einem spezifischen Namen gespeichert werden, der widerspiegelt, was die Ansicht anzeigt, zum Beispiel „`Volume-Transfers pro Tag`“.
. Auf der Inventarseite die Schaltfläche *Geplante Berichte* auswählen.
. Sie geben einen Namen für den Berichtsplan ein, füllen die anderen Berichtsfelder aus und klicken dann auf das Häkchen (image:../media/blue_check.gif[""]) am Ende der Zeile.
+
Der Bericht wird sofort als Test gesendet. Danach wird der Bericht generiert und mit der angegebenen Häufigkeit per E-Mail an die aufgeführten Empfänger gesendet.



Anhand der im Bericht dargestellten Ergebnisse können Sie die Volume-Übertragungen pro Tag untersuchen.
