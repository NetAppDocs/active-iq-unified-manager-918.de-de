= Es kann ein Bericht erstellt werden, um in Active IQ Unified Manager überbelegte Aggregate anzuzeigen.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können einen Bericht erstellen, um die Storage-Kapazität und die Nutzung von Aggregaten zu analysieren und Aggregaten anzuzeigen, die überbelegt sind.

.Bevor Sie beginnen
* Die Rolle Application Administrator oder Storage Administrator ist erforderlich.


Mit den folgenden Schritten wird eine benutzerdefinierte Ansicht erstellt, die Aggregate anzeigt, die den Schwellenwert für Überbelegung überschreiten; anschließend wird die Generierung eines Berichts für diese Ansicht geplant.

.Schritte
. Im linken Navigationsbereich erfolgt die Auswahl von *Storage* > *Aggregates*.
. Im Menü „Ansicht“ erfolgt die Auswahl von *Kapazität* > *Alle Aggregate*.
. Mit *Anzeigen/Ausblenden* können Sie alle Spalten ausblenden, die Sie im Bericht nicht benötigen.
. Die Spalte „`Overcommitted Capacity %`“ ist in der Nähe der Spalte „`Aggregate`“ zu platzieren.
. Nach dem Klicken auf das Filtersymbol können die folgenden Filter hinzugefügt und anschließend *Filter anwenden* ausgewählt werden:
+
** Überbelegte Kapazität % ist größer als 100 %


. Durch Klicken auf den oberen Bereich der Spalte „`Overcommitted Capacity %`“ werden die Ergebnisse nach Kapazitätsprozentsatz sortiert.
. Die Ansicht erhält einen spezifischen Namen, der widerspiegelt, was in der Ansicht angezeigt wird, z. B. „`Aggregates overcommitted`“; anschließend folgt ein Klick auf das Häkchen (image:../media/blue_check.gif[""]).
. Auf der Inventarseite die Schaltfläche *Geplante Berichte* auswählen.
. Über *Add Schedule* lässt sich der Seite „Berichtszeitpläne“ eine neue Zeile hinzufügen, sodass die Zeitplanmerkmale für den neuen Bericht definiert werden können.
. Sie geben einen Namen für den Berichtsplan ein, füllen die anderen Berichtsfelder aus und klicken dann auf das Häkchen (image:../media/blue_check.gif[""]) am Ende der Zeile.
+
Der Bericht wird sofort als Test gesendet. Danach wird der Bericht generiert und mit der angegebenen Häufigkeit per E-Mail an die aufgeführten Empfänger gesendet.



Basierend auf den im Bericht dargestellten Ergebnissen sollten Sie möglicherweise die Kapazität der Aggregate erhöhen oder einige Daten aus bestimmten Aggregaten verschieben.
