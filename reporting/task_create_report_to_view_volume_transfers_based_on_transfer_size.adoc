= Ein Bericht zum Anzeigen von Volume-Übertragungen basierend auf der Übertragungsgröße in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können einen Bericht erstellen, um Volume-Transfers basierend auf der Transfergröße anzuzeigen.

.Bevor Sie beginnen
* Die Rolle Application Administrator oder Storage Administrator ist erforderlich.


Mit den folgenden Schritten lässt sich eine benutzerdefinierte Ansicht für Volume-Übertragungen basierend auf der Übertragungsgröße erstellen und anschließend ein Bericht für diese Ansicht generieren.

.Schritte
. Auswahl im linken Navigationsbereich: *Storage* > *Volumes*.
. Im Menü „Ansicht“ ist *Beziehung* > *Übertragungsrate des letzten Monats* auszuwählen.
. Über den oberen Rand der Spalte „`Total Transfer Size`“ lassen sich die Volume-Übertragungen nach Größe sortieren.
. Für die Ansicht sollte ein spezifischer Name verwendet werden, der widerspiegelt, was in der Ansicht angezeigt wird, zum Beispiel „`Volumes by transfer size`“.
. Auf der Inventarseite die Schaltfläche *Geplante Berichte* auswählen.
. Sie geben einen Namen für den Berichtsplan ein, füllen die anderen Berichtsfelder aus und klicken dann auf das Häkchen (image:../media/blue_check.gif[""]) am Ende der Zeile.
+
Der Bericht wird sofort als Test gesendet. Danach wird der Bericht generiert und mit der angegebenen Häufigkeit per E-Mail an die aufgeführten Empfänger gesendet.



Anhand der im Bericht dargestellten Ergebnisse können Sie die Volume-Beziehungen nach Übertragungsgröße untersuchen.
