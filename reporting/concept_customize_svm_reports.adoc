= Anpassen von Berichten zu Speicher-VMs in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Berichte zu Storage VMs erstellen, um Volume-Informationen zu analysieren und den allgemeinen Systemstatus sowie die Storage-Verfügbarkeit anzuzeigen. Beispielsweise können Sie Berichte erstellen, um SVMs anzuzeigen, die die maximale Volume-Anzahl erreichen, und um gestoppte SVMs zu analysieren.
