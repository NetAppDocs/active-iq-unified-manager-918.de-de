= Active IQ Unified Manager REST APIs für die Berichterstellung verwenden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Mithilfe von REST APIs können Sie Ihre Cluster managen, indem Sie die von Unified Manager erfassten Informationen zu Systemstatus, Kapazität, Performance und Sicherheit einsehen.

REST APIs sind über die Swagger-Webseite verfügbar. Über die Swagger-Webseite können die Unified Manager REST API-Dokumentation angezeigt und API-Aufrufe manuell ausgeführt werden. Der Zugriff über die Unified Manager Web-UI erfolgt in der Menüleiste über die Schaltfläche *Help* und die anschließende Auswahl von *API Documentation*. Informationen zu Unified Manager REST APIs finden sich in link:../api-automation/concept_get_started_with_um_apis.html["Erste Schritte mit Active IQ Unified Manager REST APIs"].

Sie benötigen die Rolle „Operator“, „Storage Administrator“ oder „Application Administrator“, um auf die REST APIs zugreifen zu können.
