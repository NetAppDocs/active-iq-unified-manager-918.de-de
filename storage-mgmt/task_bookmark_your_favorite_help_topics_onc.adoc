= Lesezeichen für bevorzugte Hilfethemen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Im Tab „Hilfefavoriten“ können Sie häufig genutzte Hilfethemen als Lesezeichen speichern. Hilfe-Lesezeichen bieten schnellen Zugriff auf Ihre bevorzugten Themen.

.Schritte
. Zum Hilfethema navigieren, das als Favorit hinzugefügt werden soll.
. Auf *Favoriten* und anschließend auf *Hinzufügen* klicken.
