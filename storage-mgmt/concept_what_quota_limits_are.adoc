= Informationen zu Kontingentgrenzen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Benutzerkontingentgrenzen sind Werte, anhand derer der Unified Manager Server beurteilt, ob die Speicherplatznutzung eines Benutzers sich der festgelegten Grenze nähert oder diese bereits erreicht hat. Wenn die weiche Grenze überschritten wird oder das endgültige Limit erreicht ist, generiert der Unified Manager Server Benutzerkontingentereignisse.

Standardmäßig sendet der Unified Manager Server eine Benachrichtigungs-E-Mail an Benutzer, die das weiche Kontingentlimit überschritten oder das endgültige Limit erreicht haben und für die Benutzerkontingentereignisse konfiguriert sind. Benutzer mit der Rolle Application Administrator können Warnungen konfigurieren, die die angegebenen Empfänger über Kontingentereignisse von Benutzern oder Benutzergruppen benachrichtigen.

Sie können Kontingentlimits entweder mit ONTAP System Manager oder der ONTAP CLI festlegen.
