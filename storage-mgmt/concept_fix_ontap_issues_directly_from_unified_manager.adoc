= ONTAP Probleme oder Funktionen direkt über Active IQ Unified Manager verwalten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können bestimmte ONTAP Probleme beheben oder bestimmte ONTAP Funktionen direkt über die Unified Manager Benutzeroberfläche managen, anstatt den ONTAP System Manager oder die ONTAP CLI verwenden zu müssen. Die Option "`Management Actions`" bietet Korrekturen für eine Reihe von ONTAP Problemen, die Unified Manager Ereignisse ausgelöst haben.

Probleme lassen sich direkt auf der Seite „Management Actions“ beheben, wenn im linken Navigationsbereich die Option *Management Actions* ausgewählt wird. Management Actions ist außerdem über den Bereich „Management Actions“ im Dashboard, auf der Seite „Event details“ und über die Auswahl „Workload Analysis“ im linken Navigationsmenü verfügbar.

Unified Manager kann bestimmte Probleme umfassend diagnostizieren und eine einzelne Lösung bereitstellen. Für bestimmte ONTAP Funktionen, wie z. B. Anti-Ransomware Monitoring, führt Unified Manager interne Prüfungen durch und empfiehlt spezifische Maßnahmen. Sofern verfügbar, werden diese Lösungen in Management Actions mit einer Schaltfläche *Fix It* angezeigt. Über die Schaltfläche *Fix It* lässt sich das Problem beheben. Hierfür ist die Rolle Application Administrator oder Storage Administrator erforderlich.

Unified Manager sendet ONTAP Befehle an den Cluster, um die angeforderte Korrektur durchzuführen. Nach Abschluss der Korrektur gilt das Ereignis als obsolet.

Einige Verwaltungsaktionen ermöglichen es Ihnen, dasselbe Problem auf mehreren Storage Objekten mit der Schaltfläche *Fix All* zu beheben. Beispielsweise kann es 5 Volumes mit dem Ereignis "Volume Space Full" geben, das durch Klicken auf die Verwaltungsaktion *Fix All* für "Enable volume autogrow" behoben werden könnte. Mit einem Klick können Sie dieses Problem auf 5 Volumes beheben.

Informationen zu den ONTAP Problemen und Funktionen, die Sie durch automatische Behebung managen können, finden Sie unter link:../storage-mgmt/reference_what_ontap_issues_can_unified_manager_fix.html["Welche Probleme kann Unified Manager beheben"].
