= Informationen zu Quoten in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quotas ermöglichen es, den von einem Benutzer, einer Gruppe oder einem Qtree verwendeten Speicherplatz und die Anzahl der Dateien einzuschränken oder nachzuverfolgen. Quotas werden mithilfe der  `/etc/quotas`Datei angegeben. Quotas werden auf ein bestimmtes Volume oder einen bestimmten Qtree angewendet.
