= Informationen zur Funktionsweise des Cluster-Erkennungsprozesses in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nachdem Sie den Cluster zu Unified Manager hinzugefügt haben, erkennt der Server die Clusterobjekte und fügt sie seiner Datenbank hinzu. Wenn Sie verstehen, wie dieser Erkennungsprozess funktioniert, können Sie die Cluster Ihres Unternehmens und deren Objekte besser managen.

Das Standardüberwachungsintervall beträgt 15 Minuten: Wenn Sie einen Cluster zum Unified Manager Server hinzugefügt haben, dauert es 15 Minuten, bis die Clusterdetails in der Unified Manager UI angezeigt werden.
