= Erstellen und Bearbeiten von Performance Service Levels in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn die vom System definierten Performance Service Levels nicht mit Ihren Workload-Anforderungen übereinstimmen, können Sie Ihre eigenen Performance Service Levels erstellen, die für Ihre Workloads optimiert sind.

.Bevor Sie beginnen
* Sie benötigen die Rolle des Anwendungsadministrators.
* Der Name des Performance Service Level muss eindeutig sein, und die folgenden reservierten Schlüsselwörter können nicht verwendet werden:
+
`Prime`, `Extreme`, `Performance`, `Value`, `Unassigned`, `Learning`, `Idle`, `Default`, und `None`.



Auf der Seite „Performance Service Levels“ lassen sich benutzerdefinierte Performance Service Levels erstellen und bearbeiten, indem die Service Level-Ziele definiert werden, die für die Applikationen erforderlich sind, die auf Storage zugreifen.

[NOTE]
====
Ein Performance Service Level kann nicht geändert werden, wenn es derzeit einer Arbeitslast zugewiesen ist.

====
.Schritte
. Im linken Navigationsbereich ist unter *Einstellungen* *Richtlinien* > *Performance Service Levels* zu wählen.
. Auf der Seite *Performance Service Levels* wählen Sie die entsprechende Schaltfläche aus, je nachdem, ob Sie einen neuen Performance Service Level erstellen oder einen bestehenden Performance Service Level bearbeiten möchten.
+
|===
| Zu... | Folgen Sie diesen Schritten... 


 a| 
Erstellen eines neuen Performance Service Levels
 a| 
Klicken Sie auf *Add*.



 a| 
Bearbeiten eines vorhandenen Performance Service Levels
 a| 
Die Auswahl eines vorhandenen Performance Service Level und der anschließende Klick auf *Bearbeiten* sind erforderlich.

|===
+
Die Seite zum Hinzufügen oder Bearbeiten eines Performance Service Level wird angezeigt.

. Das Performance Service Level lässt sich durch Angabe der Performance-Ziele anpassen; anschließend kann durch Klicken auf *Submit* das Performance Service Level gespeichert werden.


Sie können das neue oder geänderte Performance Service Level auf Workloads (LUNs, NFS-Dateifreigaben, CIFS-Freigaben) auf der Seite „Workloads“ oder bei der Provisionierung eines neuen Workloads anwenden.
