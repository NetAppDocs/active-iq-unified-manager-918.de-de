= Aktive Ereignisse können über die Benachrichtigungsglocke in Active IQ Unified Manager angezeigt werden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Benachrichtigungsglocke (image:../media/notification_bell.png[""]) in der Menüleiste bietet eine schnelle Möglichkeit, die wichtigsten aktiven Ereignisse anzuzeigen, die Unified Manager überwacht.

Die Liste der aktiven Ereignisse zeigt die Gesamtzahl der kritischen Ereignisse, Fehler, Warnungen und Upgrade-Ereignisse auf allen Clustern an. Diese Liste enthält Ereignisse der letzten 7 Tage, jedoch keine Informationsereignisse. Über einen Link kann die Liste der Ereignisse angezeigt werden, die für Sie am relevantesten sind.

Wenn ein Cluster nicht erreichbar ist, zeigt Unified Manager diese Informationen auf dieser Seite an. Detaillierte Informationen zu einem nicht erreichbaren Cluster können durch Klicken auf die Schaltfläche „Details“ angezeigt werden. Dadurch wird die Seite mit den Ereignisdetails geöffnet. Probleme bei der Scale-Überwachung, wie z. B. geringer Speicherplatz oder RAM auf der Managementstation, werden ebenfalls auf dieser Seite angezeigt.

.Schritte
. In der Menüleiste wird image:../media/notification_bell.png[""] ausgewählt.
. Details zu allen aktiven Ereignissen lassen sich über den Ereignistext-Link anzeigen, z. B. „2 Capacity“ oder „4 Performance“.
