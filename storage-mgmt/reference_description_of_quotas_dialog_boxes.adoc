= Das Dialogfeld „Kontingente“ in Active IQ Unified Manager kann verwendet werden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die entsprechende Option auf der Registerkarte „Benutzer- und Gruppenkontingente“ in der Ansicht „Systemstatus: Alle Storage-VMs“ verwenden, um das Format der E-Mail-Benachrichtigung zu konfigurieren, die bei einem kontingentbezogenen Problem gesendet wird, und um Regeln zu konfigurieren, die E-Mail-Adressen basierend auf dem Benutzerkontingent festlegen.
