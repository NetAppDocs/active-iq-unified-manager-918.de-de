= Active IQ Unified Manager REST APIs verwenden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager bietet Ihnen REST-APIs zur Anzeige von Informationen über die Überwachung und Verwaltung Ihrer Storage-Umgebung. APIs ermöglichen außerdem die Provisionierung und Verwaltung von Storage Objekten auf Basis von Richtlinien.

Sie können ONTAP-APIs auch auf allen von ONTAP verwalteten Clustern ausführen, indem Sie das vom Unified Manager unterstützte API-Gateway verwenden.

Informationen zu Unified Manager REST APIs sind unter link:../api-automation/concept_get_started_with_um_apis.html["Erste Schritte mit Active IQ Unified Manager REST APIs"] verfügbar.
