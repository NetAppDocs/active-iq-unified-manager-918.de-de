= Zuweisung von Performance-Schwellenwertrichtlinien zu Speicherobjekten in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie weisen einem Storage Objekt eine benutzerdefinierte Performance-Schwellenwertrichtlinie zu, sodass Unified Manager ein Ereignis meldet, wenn der Wert des Performance-Zählers die Richtlinieneinstellung überschreitet.

.Bevor Sie beginnen
Sie benötigen die Rolle des Anwendungsadministrators.

Die Performance-Schwellenwertrichtlinie bzw. -richtlinien, die auf das Objekt angewendet werden sollen, müssen vorhanden sein.

Sie können jeweils nur eine Performance-Richtlinie gleichzeitig auf ein Objekt oder eine Gruppe von Objekten anwenden.

Jedem Storage Objekt können maximal drei Schwellenwertrichtlinien zugewiesen werden. Beim Zuweisen von Richtlinien zu mehreren Objekten führt Unified Manager die folgenden Aktionen aus, wenn einem der Objekte bereits die maximale Anzahl an Richtlinien zugewiesen ist:

* Anwendung der Richtlinie auf alle ausgewählten Objekte, die ihr Maximum noch nicht erreicht haben
* Objekte, die die maximale Anzahl von Richtlinien erreicht haben, bleiben unberücksichtigt
* Es wird eine Meldung angezeigt, dass die Richtlinie nicht allen Objekten zugewiesen wurde


.Schritte
. Auf der Seite „Performance-Inventar“ eines beliebigen Storage-Objekts erfolgt die Auswahl des Objekts oder der Objekte, denen eine Schwellenwertrichtlinie zugewiesen werden soll:
+
|===
| Um Schwellenwerte zuzuweisen... | Klicken... 


 a| 
Ein einzelnes Objekt
 a| 
Das Kästchen links von diesem Objekt.



 a| 
Mehrere Objekte
 a| 
Das Kästchen links neben jedem Objekt.



 a| 
Alle Objekte auf der Seite
 a| 
im image:../media/select_dropdown_65_png.gif["Auswahl des Dropdown-Symbols"] Dropdown-Menü die Option *Alle Objekte auf dieser Seite auswählen* auswählen.



 a| 
Alle Objekte desselben Typs
 a| 
Im image:../media/select_dropdown_65_png.gif["Auswahl des Dropdown-Symbols"] Dropdown-Menü wird *Alle Objekte auswählen* gewählt.

|===
+
Mithilfe der Sortier- und Filterfunktionen können Sie die Liste der Objekte auf der Inventarseite verfeinern, um die Anwendung von Schwellenwertrichtlinien auf viele Objekte zu vereinfachen.

. Nach der Auswahl erfolgt der Klick auf *Assign Performance Threshold Policy*.
+
Die Seite „Performance-Schwellenwertrichtlinie zuweisen“ wird angezeigt und zeigt eine Liste der Schwellenwertrichtlinien an, die für diesen spezifischen Storage-Objekttyp vorhanden sind.

. Bei Auswahl jeder Richtlinie werden die Details der Einstellungen für Performance-Schwellenwerte angezeigt, sodass überprüft werden kann, ob die richtige Schwellenwertrichtlinie ausgewählt wurde.
. Nachdem Sie die passende Schwellenwertrichtlinie ausgewählt haben, wählen Sie *Assign Policy* aus.
+
Eine Erfolgsmeldung am oberen Seitenrand bestätigt, dass die Schwellenwertrichtlinie dem Objekt oder den Objekten zugewiesen wurde, und bietet einen Link zur Alarmierungsseite, damit Sie die Alarmeinstellungen für dieses Objekt und diese Richtlinie konfigurieren können.



Wenn Sie Warnmeldungen per E-Mail oder als SNMP-Trap erhalten möchten, die Sie darüber informieren, dass ein bestimmtes Performance Ereignis erzeugt wurde, müssen Sie die Warnmeldungseinstellungen auf der Seite „Alert Setup“ konfigurieren.
