= Verwaltung der Performance mithilfe von QoS-Richtliniengruppeninformationen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager ermöglicht die Anzeige der QoS-Richtliniengruppen (Quality of Service), die auf allen überwachten Clustern verfügbar sind. Die Richtlinien können mit ONTAP Software (System Manager oder ONTAP CLI) oder über die Unified Manager Performance Service Level-Richtlinien definiert worden sein. Unified Manager zeigt außerdem an, bei welchen Volumes und LUNs eine QoS-Richtliniengruppe zugewiesen ist.

Weitere Informationen zum Anpassen der QoS-Einstellungen finden Sie unter  https://docs.netapp.com/us-en/ontap/performance-admin/index.html["Überblick über das Performance-Management"]
