= Leistungsereignisse nach Schweregrad in Active IQ Unified Manager priorisieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Jedes Performance-Ereignis ist einem Typ des Schweregrads zugeordnet, damit Sie die Ereignisse priorisieren können, die eine sofortige Korrekturmaßnahme erfordern.

* *Kritisch*
+
Ein Performance-Ereignis ist aufgetreten, das zu einer Dienstunterbrechung führen könnte, wenn nicht umgehend eine Korrekturmaßnahme ergriffen wird.

+
Kritische Ereignisse werden nur auf Grundlage benutzerdefinierter Schwellenwerte gesendet.

* *Warnung*
+
Ein Performance Zähler für ein Clusterobjekt liegt außerhalb des normalen Bereichs und sollte überwacht werden, um sicherzustellen, dass er nicht den kritischen Schweregrad erreicht. Ereignisse dieses Schweregrads führen nicht zu einer Dienstunterbrechung, und sofortige Korrekturmaßnahmen sind möglicherweise nicht erforderlich.

+
Benutzerdefinierte, systemdefinierte oder dynamische Schwellenwerte senden Warnereignisse.

* *Informationen*
+
Das Ereignis tritt auf, wenn ein neues Objekt erkannt oder eine Benutzeraktion ausgeführt wird. Wenn beispielsweise ein beliebiges Storage Objekt gelöscht wird oder Konfigurationsänderungen vorgenommen werden, wird ein Ereignis mit dem Typ des Schweregrads Information generiert.

+
Informationsereignisse werden direkt von ONTAP gesendet, wenn eine Konfigurationsänderung erkannt wird.
