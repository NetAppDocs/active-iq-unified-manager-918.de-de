= Einrichten einer Verbindung zwischen Active IQ Unified Manager und einem externen Datenanbieter
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Eine Verbindung zwischen einem Unified Manager Server und einem externen Datenanbieter ermöglicht es Ihnen, Cluster Performance-Daten an einen externen Server zu senden, sodass Storage Manager die Performance-Kennzahlen mithilfe von Drittanbietersoftware grafisch darstellen können.

Eine Verbindung zwischen einem Unified Manager Server und einem externen Daten-Provider wird über die Menüoption „`External Data Provider`“ in der Wartungs-Managementplattform eingerichtet.
