= Analyse von Ereignissen aus systemdefinierten Leistungsschwellenwerten in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ereignisse, die durch systemdefinierte Performance Schwellenwerte generiert werden, zeigen an, dass ein Performance-Zähler oder eine Gruppe von Performance-Zählern für ein bestimmtes Storage Objekt den Schwellenwert aus einer systemdefinierten Richtlinie überschritten hat. Dies weist darauf hin, dass bei dem Storage Objekt, beispielsweise einem Aggregat oder Knoten, ein Performance-Problem vorliegt.

Die Seite mit den Ereignisdetails dient zur Analyse des Performance-Ereignisses und gegebenenfalls zur Ergreifung einer Korrekturmaßnahme, um die Performance wieder auf den Normalzustand zurückzuführen.

[NOTE]
====
Systemdefinierte Schwellenwertrichtlinien sind auf Cloud Volumes ONTAP, ONTAP Edge oder ONTAP Select Systemen nicht aktiviert.
