= Entfernen von Leistungsschwellenwertrichtlinien von Speicherobjekten in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können eine benutzerdefinierte Performance-Schwellenwertrichtlinie von einem Storage Objekt entfernen, wenn Unified Manager den Wert des Performance-Zählers nicht mehr überwachen soll.

.Bevor Sie beginnen
Sie benötigen die Rolle des Anwendungsadministrators.

Sie können jeweils nur eine Richtlinie aus einem ausgewählten Objekt entfernen.

Sie können eine Schwellenwertrichtlinie aus mehreren Storage Objekten entfernen, indem Sie in der Liste mehr als ein Objekt auswählen.

.Schritte
. Auf der Seite *Inventar* eines beliebigen Storage-Objekts lassen sich ein oder mehrere Objekte auswählen, auf die mindestens eine Performance-Schwellenwertrichtlinie angewendet wurde.
+
|===
| Zum Löschen von Schwellenwerten aus... | Folgendes ist zu tun... 


 a| 
Ein einzelnes Objekt
 a| 
Das Kästchen links neben diesem Objekt wird ausgewählt.



 a| 
Mehrere Objekte
 a| 
Das Kästchen links neben jedem Objekt auswählen.



 a| 
Alle Objekte auf der Seite
 a| 
Die Auswahl von image:../media/select_dropdown_65_png.gif["Auswahl des Dropdown-Symbols"] erfolgt in der Spaltenüberschrift.

|===
. Dann erfolgt die Auswahl von *Clear Performance Threshold Policy*.
+
Auf der Seite „Schwellenwertrichtlinie löschen“ erscheint eine Liste der Schwellenwertrichtlinien, die den Storage-Objekten aktuell zugewiesen sind.

. Die Schwellenwertrichtlinie, die aus den Objekten entfernt werden soll, auswählen und auf *Richtlinie löschen* klicken.
+
Wenn Sie eine Schwellenwertrichtlinie auswählen, erscheinen die Details der Richtlinie, sodass Sie bestätigen können, dass Sie die richtige Richtlinie ausgewählt haben.
