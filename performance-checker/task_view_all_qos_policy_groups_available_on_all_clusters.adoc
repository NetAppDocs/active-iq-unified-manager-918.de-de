= In Active IQ Unified Manager verfügbare QoS-Richtliniengruppen auf allen Clustern anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können eine Liste aller QoS-Richtliniengruppen anzeigen, die auf den von Unified Manager überwachten Clustern verfügbar sind. Dies umfasst herkömmliche QoS-Richtlinien, adaptive QoS-Richtlinien und QoS-Richtlinien, die durch Unified Manager Performance Service Level Richtlinien verwaltet werden.

.Schritte
. Im linken Navigationsbereich erfolgt die Auswahl von *Storage* > *QoS-Richtliniengruppen*.
+
Standardmäßig wird die Ansicht „Performance: Herkömmliche QoS-Richtliniengruppen“ angezeigt.

. Die detaillierten Konfigurationseinstellungen für jede verfügbare traditionelle QoS-Richtliniengruppe werden angezeigt.
. Über die Schaltfläche zum Erweitern (image:../media/chevron_down.gif[""]) neben dem Namen der QoS-Richtliniengruppe können weitere Details zur Richtliniengruppe aufgerufen werden.
. Im Menü „Ansicht“ kann eine der zusätzlichen Optionen ausgewählt werden, um alle adaptiven QoS-Richtliniengruppen oder alle QoS-Richtliniengruppen anzuzeigen, die mit Unified Manager Performance Service Levels erstellt wurden.
