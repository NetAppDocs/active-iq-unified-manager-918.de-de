= Der Bereich „Zählerdiagramme“ in Active IQ Unified Manager kann erweitert werden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können den Bereich „Zählerdiagramme“ erweitern, sodass die Diagramme größer und besser lesbar sind.

Nachdem Sie die Vergleichsobjekte und den Zeitbereich für Zähler definiert haben, können Sie einen größeren Bereich „Counter Charts“ anzeigen. Die Schaltfläche *<* in der Mitte des Performance Explorer Fensters dient zum Erweitern des Bereichs.

.Schritt
. Erweitern oder Verkleinern des Bereichs *Zählerdiagramme*.


|===
| Zu... | Folgendes ist zu tun... 


 a| 
Erweiterung des Bereichs „Zählerdiagramme“ auf die Breite der Seite
 a| 
Die Schaltfläche *<* auswählen



 a| 
Verkleinern des Bereichs „Zählerdiagramme“ auf die rechte Seitenhälfte
 a| 
Auf die Schaltfläche *>* klicken

|===
