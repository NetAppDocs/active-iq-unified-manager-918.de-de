= Netzwerkschnittstellenereignisse in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ereignisse für Netzwerkschnittstellen liefern Informationen über den Status Ihrer Netzwerkschnittstellen (LIFs), sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Impact Level, den Quelltyp und den Schweregrad.
