= Hier wird erläutert, wie Active IQ Unified Manager ein empfangenes Ereignis verarbeitet
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn Unified Manager ein Ereignis empfängt, erscheint es auf der Dashboard-Seite, auf der Inventarseite „Event Management“, auf den Registerkarten „Summary“ und „Explorer“ der Seite „Cluster/Performance“ sowie auf der objektspezifischen Inventarseite (z. B. der Inventarseite „Volumes/Health“).

Wenn Unified Manager mehrere aufeinanderfolgende Vorkommen desselben Ereigniszustands für dieselbe Clusterkomponente erkennt, behandelt er alle Vorkommen als ein einziges Ereignis und nicht als separate Ereignisse. Die Dauer des Ereignisses erhöht sich, um anzuzeigen, dass das Ereignis noch aktiv ist.

Je nachdem, wie Sie die Einstellungen auf der Seite „Benachrichtigungseinrichtung“ konfigurieren, können Sie andere Benutzer über diese Ereignisse benachrichtigen. Die Benachrichtigung löst folgende Aktionen aus:

* Eine E-Mail über das Ereignis kann an alle Benutzer mit der Rolle Unified Manager Administrator gesendet werden.
* Das Ereignis kann an zusätzliche E-Mail-Empfänger gesendet werden.
* Ein SNMP Trap lässt sich an den Trap-Empfänger senden.
* Mit einem benutzerdefinierten Skript lässt sich eine Aktion ausführen.
