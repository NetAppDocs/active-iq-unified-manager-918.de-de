= Hinzufügen von Warnmeldungen für Leistungsereignisse in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Benachrichtigungen für einzelne Performance-Ereignisse genauso konfigurieren wie für alle anderen Ereignisse, die von Unified Manager empfangen werden. Wenn Sie außerdem alle Performance-Ereignisse gleich behandeln und E-Mails an dieselbe Person senden möchten, können Sie eine einzelne Benachrichtigung erstellen, die Sie informiert, sobald kritische oder Warnungs-Performance-Ereignisse ausgelöst werden.

.Bevor Sie beginnen
Die Rolle Application Administrator oder Storage Administrator ist erforderlich.

Das folgende Beispiel zeigt, wie ein Ereignis für alle kritischen Latenz-, IOPS- und MBps-Ereignisse erstellt wird. Mit derselben Methode können Ereignisse aus allen Performance-Zählern und für alle Warnereignisse ausgewählt werden.

.Schritte
. Im linken Navigationsbereich auf *Storage Management* > *Alert Setup* klicken.
. Auf der Seite *Alarmeinstellungen* *Hinzufügen* auswählen.
. Im Dialogfeld *Warnung hinzufügen* auf *Name* klicken und einen Namen sowie eine Beschreibung für die Warnung eingeben.
. Auf der Seite *Ressourcen* werden keine Ressourcen ausgewählt.
+
Da keine Ressourcen ausgewählt sind, gilt die Warnung für alle Cluster, Aggregate, Volumes usw., für die diese Ereignisse empfangen werden.

. Nach Auswahl von *Events* können die folgenden Aktionen durchgeführt werden:
+
.. In der Liste „Ereignisschweregrad“ erfolgt die Auswahl von *Kritisch*.
.. Im Feld „Ereignisname enthält“ können Sie *`latency`* eingeben und anschließend auf den Pfeil klicken, um alle übereinstimmenden Ereignisse auszuwählen.
.. Im Feld „Ereignisname enthält“ *`iops`* eingeben und anschließend auf den Pfeil klicken, um alle übereinstimmenden Ereignisse auszuwählen.
.. Im Feld „Ereignisname enthält“ können Sie *`mbps`* eingeben und dann auf den Pfeil klicken, um alle übereinstimmenden Ereignisse auszuwählen.


. Unter *Aktionen* folgt im Feld *Diese Benutzer benachrichtigen* die Auswahl des Namens des Benutzers, der die Benachrichtigungs-E-Mail erhalten soll.
. Auf dieser Seite können Sie alle weiteren Optionen für das Senden von SNMP-Traps und das Ausführen eines Skripts konfigurieren.
. Auf *Speichern* klicken.
