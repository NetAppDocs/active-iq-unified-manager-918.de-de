= Informationen zu NVMe Namespace Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NVMe Namespace Ereignisse liefern Ihnen Informationen über den Status Ihrer Namespaces, sodass potenzielle Probleme überwacht werden können. Die Ereignisse sind nach Wirkungsbereichen gruppiert und enthalten den Ereignis- und Trap-Namen, das Auswirkungslevel, den Quelltyp und den Schweregrad.

Ein Sternchen (*) kennzeichnet EMS-Ereignisse, die in Unified Manager-Ereignisse umgewandelt wurden.
