= Informationen zu SnapMirror Beziehung Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapMirror Beziehungsereignisse liefern Ihnen Informationen über den Status Ihrer asynchronen und synchronen SnapMirror Beziehungen, sodass Sie potenzielle Probleme überwachen können. Asynchrone SnapMirror Beziehungsereignisse werden sowohl für Storage VMs als auch für Volumes generiert, synchrone SnapMirror Beziehungsereignisse dagegen nur für Volume Beziehungen. Für einzelne Volumes, die Teil von Disaster-Recovery-Beziehungen von Storage VMs sind, werden keine Ereignisse generiert. Die Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Impact Level, den Quelltyp und den Schweregrad.



[[impact-area-protection]]
== Wirkungsbereich: Schutz

Ein Sternchen (*) kennzeichnet EMS-Ereignisse, die in Unified Manager-Ereignisse umgewandelt wurden.

[NOTE]
====
Die SnapMirror Beziehungsereignisse werden für Storage VMs generiert, die durch die Disaster Recovery von Storage VMs geschützt sind, jedoch nicht für Beziehungen zwischen einzelnen Objekten.
