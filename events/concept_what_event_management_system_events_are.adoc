= Informationen zu Ereignissen des Event Management System in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das Event Management System (EMS) erfasst Ereignisdaten aus verschiedenen Teilen des ONTAP Kernels und stellt Mechanismen zur Ereignisweiterleitung bereit. Diese ONTAP Ereignisse können im Unified Manager als EMS Ereignisse gemeldet werden. Die zentrale Überwachung und Verwaltung vereinfacht die Konfiguration kritischer EMS Ereignisse und Warnbenachrichtigungen auf der Grundlage dieser EMS Ereignisse.

Beim Hinzufügen des Clusters zu Unified Manager wird dem Cluster die Unified Manager-Adresse als Benachrichtigungsziel hinzugefügt. Ein EMS-Ereignis wird gemeldet, sobald es im Cluster auftritt.

Es gibt zwei Methoden zum Empfangen von EMS-Ereignissen im Unified Manager:

* Eine bestimmte Anzahl wichtiger EMS Ereignisse wird automatisch gemeldet.
* Sie können einzelne EMS-Ereignisse abonnieren.


Die von Unified Manager generierten EMS-Ereignisse werden je nach der Methode, mit der das Ereignis generiert wurde, unterschiedlich gemeldet:

[NOTE]
====
Einige der neuen automatischen EMS-Ereignisse sind Informationsereignisse, die anzeigen, dass ein vorheriges Ereignis behoben wurde. Beispielsweise zeigt das Informationsereignis "FlexGroup Constituents Space Status All OK" an, dass das Fehlerereignis "FlexGroup Constituents Have Space Issues" behoben wurde. Informationsereignisse können nicht mit demselben Ereignislebenszyklus verwaltet werden wie andere Ereignisse nach Typ des Schweregrads; das Ereignis wird jedoch automatisch als veraltet markiert, wenn dasselbe Volume ein weiteres Fehlerereignis "`Space Issues`" erhält.
