= Informationen zu Flash-Karten-Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Flash Kartenereignisse liefern Ihnen Informationen über den Status der auf Knoten in Ihrem Datacenter installierten Flash Karten, sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Auswirkungslevel, den Quelltyp und den Schweregrad.
