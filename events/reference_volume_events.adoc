= Informationen zu Volume-Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Volume-Ereignisse liefern Informationen über den Status von Volumes und ermöglichen so die Überwachung potenzieller Probleme. Die Ereignisse sind nach Wirkungsbereich gruppiert und enthalten Ereignisname, Trap-Name, Level, Quelltyp und Schweregrad.

Ein Sternchen (*) kennzeichnet EMS-Ereignisse, die in Unified Manager-Ereignisse umgewandelt wurden.
