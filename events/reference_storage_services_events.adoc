:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Storage Services Ereignisse liefern Ihnen Informationen zur Erstellung und zum Abonnement von Storage Services, sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Wirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Auswirkungs-Level, den Quelltyp und den Schweregrad.
