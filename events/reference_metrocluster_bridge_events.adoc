= Informationen zu MetroCluster Bridge Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MetroCluster Bridge-Ereignisse liefern Informationen zum Status der Bridges, sodass Sie potenzielle Probleme in einer MetroCluster over FC Konfiguration überwachen können. Die Ereignisse sind nach Wirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, den Impact Level, den Quelltyp und den Schweregrad.
