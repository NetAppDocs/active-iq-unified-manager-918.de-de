= Informationen zu Management Stationsereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Ereignisse der Managementstation liefern Ihnen Informationen über den Status des Servers, auf dem Unified Manager installiert ist, sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Wirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Level, den Quelltyp und den Schweregrad.

[NOTE]
====
Diese beiden letzten Performance-Ereignisse waren nur für Unified Manager 7.2 verfügbar. Wenn eines dieser Ereignisse den Status „Neu“ aufweist und Sie anschließend auf eine neuere Version der Unified Manager Software aktualisieren, werden die Ereignisse nicht automatisch gelöscht. Sie müssen die Ereignisse manuell in den Status „Gelöst“ verschieben.
