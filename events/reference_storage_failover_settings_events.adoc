= Informationen zu Ereignissen bei Storage-Failover-Einstellungen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ereignisse zu den Storage Failover Einstellungen (SFO) liefern Ihnen Informationen darüber, ob Ihr Storage Failover deaktiviert oder nicht konfiguriert ist, sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Auswirkungsbereich gruppiert und umfassen den Ereignis- und Trap-Namen, das Auswirkungs-Level, den Quelltyp und den Schweregrad.
