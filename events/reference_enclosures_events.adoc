= Informationen zu Gehäuseereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gehäuseereignisse liefern Ihnen Informationen über den Status von Disk Shelf Gehäusen in Ihrem Datacenter, sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Impact Level, den Quelltyp und den Schweregrad.

* Cluster, die sich in einer MetroCluster Konfiguration befinden
* Die folgenden Plattformen: FAS2554, FAS2552, FAS2520 und FAS2240
