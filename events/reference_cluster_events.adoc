= Informationen zu Clusterereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Clusterereignisse liefern Informationen über den Status von Clustern und ermöglichen so die Überwachung der Cluster auf potenzielle Probleme. Die Ereignisse sind nach Wirkungsbereich gruppiert und enthalten Ereignisname, Trap-Name, Level, Quelltyp und Schweregrad.
