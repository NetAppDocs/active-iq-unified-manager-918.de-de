= Informationen zu MetroCluster Switch-Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MetroCluster Switch-Ereignisse für MetroCluster over FC Konfigurationen bieten Informationen zum Status der MetroCluster Switches, um potenzielle Probleme zu überwachen. Die Ereignisse sind nach Wirkungsbereich gruppiert und enthalten Ereignis- und Trap-Name, Impact Level, Quelltyp und Schweregrad.
