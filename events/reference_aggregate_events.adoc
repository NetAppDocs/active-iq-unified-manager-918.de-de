= Informationen zu Aggregatereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Aggregatereignisse liefern Ihnen Informationen über den Status von Aggregaten, sodass Sie potenzielle Probleme überwachen können. Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Impact Level, den Quelltyp und den Schweregrad.
