= Informationen zu Inode-Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Inode-Ereignisse liefern Informationen dazu, wann ein Inode voll oder nahezu voll ist, sodass eine Überwachung auf potenzielle Probleme möglich ist. Die Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Auswirkungs-Level, den Quelltyp und den Schweregrad.
