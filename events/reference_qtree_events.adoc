= Informationen zu Qtree-Ereignissen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Qtree Ereignisse liefern Ihnen Informationen über die qtree Kapazität sowie über Datei- und Festplattenbeschränkungen, sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Impact Level, den Quelltyp und den Schweregrad.
