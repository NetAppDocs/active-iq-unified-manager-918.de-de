= Informationen zu Statusereignissen bei Volume Moves in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Statusereignisse für Volume Verschiebungen informieren Sie über den Status Ihrer Volume Verschiebung, sodass Sie potenzielle Probleme überwachen können. Die Ereignisse sind nach Auswirkungsbereich gruppiert und enthalten den Ereignis- und Trap-Namen, das Auswirkungs Level, den Quelltyp und den Schweregrad.
