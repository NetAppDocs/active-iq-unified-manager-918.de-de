= Die Liste und Details der Storage-VMs in Active IQ Unified Manager anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
In der Ansicht „Systemstatus: Alle Storage VMs“ können Sie Ihren Bestand an Storage Virtual Machines (SVMs) überwachen. Die Detailseite „Storage VM / Systemstatus“ enthält detaillierte Informationen zu den überwachten SVMs.

.Bevor Sie beginnen
Sie benötigen die Rolle „Operator“, „Application Administrator“ oder „Storage Administrator“.

Sie können SVM-Details wie Kapazität, Effizienz und Konfiguration einer SVM einsehen. Außerdem können Sie Informationen zu den zugehörigen Geräten und Warnmeldungen für diese SVM abrufen.

.Schritte
. Die Auswahl erfolgt im linken Navigationsbereich über *Storage* > *Storage VMs*.
. Eine der folgenden Möglichkeiten kann verwendet werden, um die SVM-Details anzuzeigen:
+
** Informationen über den Systemstatus aller SVMs in allen Clustern sind über das Menü „Ansicht“ in der Ansicht „Systemstatus: Alle Storage VMs“ verfügbar.
** Die vollständigen Details lassen sich durch Klicken auf den Namen der Storage VM anzeigen.
+
Sie können die vollständigen Details auch einsehen, indem Sie im Dialogfeld „Minimale Details“ auf *Details anzeigen* klicken.



. Im Dialogfeld „Minimale Details“ können die mit der SVM verknüpften Objekte durch Klicken auf *Verwandte Objekte anzeigen* angezeigt werden.
