= Sicherheitsereignisse, die möglicherweise Software- oder Firmware-Updates in Active IQ Unified Manager erfordern, können angezeigt werden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es gibt bestimmte Sicherheitsereignisse, die den Wirkungsbereich „Upgrade“ haben. Diese Ereignisse werden von der Active IQ Plattform gemeldet und identifizieren Probleme, deren Behebung ein Upgrade der ONTAP Software, der Node-Firmware oder der Betriebssystemsoftware (bei Sicherheitshinweisen) erfordert.

.Bevor Sie beginnen
Sie benötigen die Rolle „Operator“, „Application Administrator“ oder „Storage Administrator“.

Bei einigen dieser Probleme können möglicherweise sofortige Korrekturmaßnahmen erforderlich sein, während andere bis zur nächsten planmäßigen Wartung warten können. Alle diese Ereignisse können angezeigt und Benutzern zugewiesen werden, die die Probleme beheben können. Wenn es bestimmte Ereignisse für Sicherheitsupgrades gibt, zu denen Sie nicht benachrichtigt werden möchten, kann diese Liste bei der Identifizierung dieser Ereignisse helfen, damit sie deaktiviert werden können.

.Schritte
. Im linken Navigationsbereich auf *Event Management* klicken.
+
Standardmäßig werden auf der Inventarseite „Event Management“ alle aktiven Ereignisse (Neu und Bestätigt) angezeigt.

. Im Menü „View“ erfolgt die Auswahl von *Upgrade events*.
+
Die Seite zeigt alle aktiven Upgrade-Sicherheitsereignisse an.
