= Sicherung und Wiederherstellung mithilfe von NetApp Snapshots in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Eine NetApp Snapshot Kopie erstellt ein zeitpunktgenaues Image der Unified Manager Datenbank und der Konfigurationsdateien, das im Falle eines Systemausfalls oder Datenverlusts zur Wiederherstellung verwendet werden kann. Die Snapshot Kopie wird regelmäßig in ein Volume auf einem Ihrer ONTAP Cluster geschrieben, damit stets eine aktuelle Kopie verfügbar ist.

[NOTE]
====
Diese Funktionalität ist für Active IQ Unified Manager, der auf einer virtuellen Appliance installiert ist, nicht verfügbar.

====
