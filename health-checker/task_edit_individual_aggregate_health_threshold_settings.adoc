= Bearbeitung individueller Einstellungen für Integritätsgrenzwerte von Aggregaten in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die Systemstatus-Schwellenwerteinstellungen für Aggregatkapazität, Wachstum und Snapshot-Kopien eines oder mehrerer Aggregate bearbeiten. Wenn ein Schwellenwert überschritten wird, werden Warnungen generiert, und Sie erhalten Benachrichtigungen. Diese Benachrichtigungen helfen Ihnen, auf Grundlage des generierten Ereignisses Präventivmaßnahmen zu ergreifen.

.Bevor Sie beginnen
Die Rolle Application Administrator oder Storage Administrator ist erforderlich.

Auf Grundlage von Änderungen der Schwellenwerte werden Ereignisse im nächsten Überwachungszyklus generiert oder als veraltet markiert.

Wenn Autogrow auf Volumes aktiviert ist, die sich auf dem Aggregat befinden, gelten die Kapazitätsschwellenwerte des Aggregats anhand der von Autogrow festgelegten maximalen Volume-Größe als überschritten und nicht anhand der ursprünglichen Volume-Größe.

.Schritte
. Im linken Navigationsbereich erfolgt die Auswahl von *Storage* > *Aggregates*.
. In der Ansicht *Systemstatus: Alle Aggregate* ist die Auswahl eines oder mehrerer Aggregate möglich; anschließend kann auf *Schwellenwerte bearbeiten* geklickt werden.
. Im Dialogfeld *Edit Aggregate Thresholds* können Sie die Schwellenwerteinstellungen für eine der folgenden Kategorien bearbeiten: Kapazität, Wachstum oder Snapshot-Kopien, indem Sie das entsprechende Kästchen auswählen und anschließend die Einstellungen ändern.
. Auf *Speichern* klicken.
