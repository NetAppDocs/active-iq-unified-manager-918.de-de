= Informationen zu Gruppen in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Eine Gruppe ist eine dynamische Sammlung heterogener Storage Objekte (Cluster, SVMs oder Volumes). Sie können in Unified Manager Gruppen erstellen, um eine Reihe von Storage Objekten einfach zu managen. Die Mitglieder einer Gruppe können sich ändern, je nachdem, welche Storage Objekte Unified Manager zu einem bestimmten Zeitpunkt überwacht.

* Jede Gruppe hat einen eindeutigen Namen.
* Sie müssen für jede Gruppe mindestens eine Gruppenregel konfigurieren.
* Sie können eine Gruppe mit mehr als einer Gruppenregel verknüpfen.
* Jede Gruppe kann mehrere Arten von Storage-Objekten wie z. B. Cluster, SVMs oder Volumes enthalten.
* Storage-Objekte werden einer Gruppe dynamisch hinzugefügt, je nachdem, wann eine Gruppenregel erstellt wird oder wann Unified Manager einen Überwachungszyklus abschließt.
* Sie können gleichzeitig Aktionen auf alle Storage Objekte in einer Gruppe anwenden, beispielsweise das Festlegen von Schwellenwerten für Volumes.
