= Die Liste der Anmerkungen und Details in Active IQ Unified Manager anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die Liste der Annotationen anzeigen, die dynamisch Clustern, Volumes und Storage Virtual Machines (SVMs) zugeordnet sind. Außerdem können Sie Details wie die Beschreibung, erstellt von, Erstellungsdatum, Werte, Regeln und die mit der Annotation verknüpften Objekte einsehen.

.Schritte
. Auswahl im linken Navigationsbereich: *Storage Management* > *Annotations*.
. Im Reiter *Anmerkungen* zeigt ein Klick auf den Namen der Anmerkung die zugehörigen Details an.
