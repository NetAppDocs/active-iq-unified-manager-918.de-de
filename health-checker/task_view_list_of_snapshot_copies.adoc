= Die Liste der Snapshot-Kopien in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die Liste der Snapshot-Kopien für ein ausgewähltes Volume anzeigen. Mithilfe der Liste der Snapshot-Kopien können Sie berechnen, wie viel Speicherplatz freigegeben werden kann, wenn eine oder mehrere Snapshot-Kopien gelöscht werden, und Sie können die Snapshot-Kopien bei Bedarf löschen.

.Bevor Sie beginnen
* Sie benötigen die Rolle „Operator“, „Application Administrator“ oder „Storage Administrator“.
* Das Volume, das die Snapshot Kopien enthält, muss online sein.


.Schritte
. Auswahl im linken Navigationsbereich: *Storage* > *Volumes*.
. In der Ansicht *Systemstatus: Alle Volumes* erfolgt die Auswahl des Volumes, das die anzuzeigenden Snapshot Kopien enthält.
. Auf der Detailseite *Volume / Systemstatus* ist die Registerkarte *Kapazität* auszuwählen.
. Im Bereich *Details* der Registerkarte *Capacity* wird im Abschnitt „Weitere Details“ der Link neben *Snapshot Copies* ausgewählt.
+
Die Anzahl der Snapshot-Kopien ist ein Link, der die Liste der Snapshot-Kopien anzeigt.
