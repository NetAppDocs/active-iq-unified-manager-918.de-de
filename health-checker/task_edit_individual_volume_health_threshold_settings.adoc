= Bearbeiten einzelner Einstellungen für Integritätsschwellenwerte von Volumes in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die Systemstatus-Schwellenwerteinstellungen für Volume-Kapazität, Wachstum, Kontingent und Speicherplatzreserve eines oder mehrerer Volumes bearbeiten. Wenn ein Schwellenwert überschritten wird, werden Warnungen generiert, und Sie erhalten Benachrichtigungen. Diese Benachrichtigungen helfen Ihnen, auf der Grundlage des generierten Ereignisses präventive Maßnahmen zu ergreifen.

.Bevor Sie beginnen
Die Rolle Application Administrator oder Storage Administrator ist erforderlich.

Auf Grundlage von Änderungen der Schwellenwerte werden Ereignisse im nächsten Überwachungszyklus generiert oder als veraltet markiert.

Bei einem Volume mit aktiviertem Autogrow gelten Kapazitätsschwellenwerte auf Grundlage der durch Autogrow festgelegten maximalen Volume-Größe als überschritten, nicht auf Grundlage der ursprünglichen Volume-Größe.

[NOTE]
====
Der Standardwert von 1000 Snapshot-Kopien gilt nur für FlexVol Volumes, wenn die ONTAP-Version 9.4 oder höher ist, und für FlexGroup Volumes, wenn die ONTAP-Version 9.8 oder höher ist. Bei Clustern, auf denen ältere Versionen der ONTAP-Software installiert sind, beträgt die maximale Anzahl 250 Snapshot-Kopien pro Volume. Für diese älteren Versionen interpretiert Unified Manager die Zahl 1000 (und jede Zahl zwischen 1000 und 250) als 250; das bedeutet, dass Sie weiterhin Ereignisse erhalten, wenn die Anzahl der Snapshot-Kopien 250 erreicht. Wenn dieser Schwellenwert für diese älteren Versionen auf weniger als 250 gesetzt werden soll, muss der Schwellenwert hier in der Ansicht „Systemstatus: Alle Volumes“ oder auf der Detailseite „Volume / Systemstatus“ auf 250 oder weniger gesetzt werden.

====
.Schritte
. Auswahl im linken Navigationsbereich: *Storage* > *Volumes*.
. In der Ansicht *Systemstatus: Alle Volumes* lassen sich ein oder mehrere Volumes auswählen; anschließend kann auf *Schwellenwerte bearbeiten* geklickt werden.
. Im Dialogfeld *Volume-Schwellenwerte bearbeiten* können Sie die Schwellenwerteinstellungen für eine der folgenden Optionen bearbeiten: Kapazität, Snapshot Kopien, qtree-Kontingent, Wachstum oder Inodes, indem Sie das entsprechende Kästchen auswählen und anschließend die Einstellungen ändern.
. Auf *Speichern* klicken.
